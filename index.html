      这个站是怎么做出来的

      弱网坞不卖软件，也不做排行榜。它只做一件事：把软件与工具的官方下载入口整理干净。

      01
      只跳官方源

      所有已上架工具的下载地址都来自厂商自己的域名或官方 CDN。本站不转存安装包，不改包，不塞下载器。

      02
      链接逐条实测

      收录时对每个地址发起真实请求，确认返回的是可执行文件而不是网页，并把 HTTP 状态、Content-Type、真实字节数写进详情页。

      03
      体积是真实字节

      卡片上的文件大小来自服务器返回的 Content-Length，不是估算；下载前你就能知道要花多少流量。

      04
      无账号、无统计

      站点没有登录、没有埋点 SDK。收藏和主题偏好只存在你自己的浏览器 localStorage 里，不会上传。

      05
      更新怎么处理

      对托管在 GitHub Releases 的软件，详情页可以现场查询最新版本；查到更新会直接换成新的官方资产地址。
